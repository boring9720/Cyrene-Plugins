# 聊天记录导出

把本地聊天存档导出为人可读的 HTML / Markdown 文件：还原聊天气泡界面、双方头像、思考过程与工具调用折叠展示。纯用户侧工具，不注册 Agent 工具、不联网。

## 功能

- 图形界面勾选会话，支持标题搜索、全选、跨搜索多选
- HTML：自包含单文件，双击即看；聊天气泡布局，双方头像 base64 内嵌，离线可看
- Markdown：正文 + 折叠的思考过程 / 工具调用，适合二次编辑归档
- 内容还原：时间戳、表情包标注、图片附件内嵌、渠道来源标注（微信 / 飞书 / QQ）
- 导出目录自选，文件名自动清洗 Windows 非法字符，重名自动编号
- 只读解析本地存档，不修改、不上传任何数据

## 安装与使用

1. 在 Cyrene 的插件页选择本插件 ZIP，安装后启用并打开。
2. 在会话列表中勾选要导出的会话，可按标题搜索过滤。
3. 选择导出格式（HTML / Markdown），点击「导出所选会话」。
4. 选择保存目录，完成后可一键打开所在文件夹。

## 头像与个性化

- 昔涟头像默认读取 `C:\Users\<用户名>\Pictures\头像\昔涟.png`，路径写在 `index.cjs` 顶部 `ASSISTANT_AVATAR_PATH` 常量，可自行修改
- 用户头像自动使用 Cyrene 内上传的头像；未上传时显示程序绘制的默认头像
- 双方显示名（默认「昔涟」「用户」）在 `index.cjs` 顶部常量中修改

## 权限、网络与数据

- 不申请任何宿主权限（manifest 无 deps），不向 Agent 暴露任何工具
- 仅读取本地聊天存档目录，全程只读，不联网、无遥测
- 图片附件以 base64 内嵌进 HTML，图片较多时文件会较大，属正常现象
